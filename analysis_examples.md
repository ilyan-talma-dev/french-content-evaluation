# French Text Analysis Examples

Example 1

Text:
Il pleut des cordes.

Literal translation:
It is raining ropes.

Actual meaning:
It is raining heavily.

Explanation:
This is a common French idiomatic expression. Literal translation would be incorrect.
Understanding idioms is important when evaluating language outputs.


Example 2

Text:
Il a posé un lapin.

Literal translation:
He placed a rabbit.

Actual meaning:
He stood someone up.

Explanation:
This expression cannot be interpreted word-for-word. Cultural and contextual understanding is required.
